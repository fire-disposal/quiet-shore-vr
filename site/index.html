躺在床上，

静岸是一套在床边完成的沉浸式场景体验。患者躺着或半躺，头显里是一处安静的景物——湖面、光井或病房立便间；场景、起伏与语音由床边的平板控制，随时可以停止。设备离线运行，画面与会话数据不离开这两台设备。

下载头显端 APK 下载平板端 APK

最新版本 · 发布说明 · SHA256 · GitHub 备用

01

头显端

控制台、BLE 外设与本地页面。患者在 Firefox Reality 中完成一次确认，进入校准或训练。

02

控制端

平板通过蓝牙接管。场景、眼高、声音、SUS 量表与虚拟起身都在一个操作台里。

03

离线优先

页面走 127.0.0.1；控制命令走 BLE。没有云端账号，也不把训练数据上传。
