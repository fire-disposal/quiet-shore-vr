# 界面验收：五个面、一套判据

状态：2026-11-12。对象是 v1.0.0 的四块人可见表面。判据只写"能不能用"，不写偏好；每条都要能用命令或截图复现。

截图工具：`./scripts/tablet-shots.sh`（模拟器 `qs_tablet`，只读，不装包、不改系统设置）。

## 1 平板控制台（Jetpack Compose）

| 状态 | 截图 | 判据 |
| --- | --- | --- |
| 待机 | `console-idle.png` | 命令栏显示连接态与场景；看板四个数有值或明确的占位；快捷行可用；不出现"训练中" |
| 等待按压 | `console-entry.png` | 会话态写"等待患者确认"，并给出已过秒数；结束/急停可用 |
| 记录体位 | `console-calibrating.png` | 场景与强度禁用；只有急停可点；不出现可点的"结束本次" |
| 训练中 | `console-running.png` | 场景/强度/语音/结束都在一行内；**全屏只有一处"场景"入口**；镜像与带列并排；底部不被系统任务栏压住 |
| 正在结束 | `console-stopping.png` | 场景与强度禁用并在原位写明原因；会话态写"正在结束" |
| 低电量 | `console-lowbattery.png` | 电量 ≤20% 时数字在 ice 实心块上、压墨字；其余文字不变色 |
| 设备不足 | — | 未连接时命令栏能看出"未连接"，且"断开"不可点 |

跨状态的硬规则：

1. **切角/细线框 = 可按**；一段文字不能当作按钮（`说明 / 断开 / 退出场景 / 退出系统` 都必须在形状里）。
2. 命令栏第二行**不出现单标签空栏**；不需要 rail 时整行删掉。
3. 急停永远在命令栏、不属于任何滚动容器、不参与任何弹窗。
4. 所有触控目标 ≥48dp。

## 2 患者入口页（WebXR 前的一屏）

| 判据 | 复现 |
| --- | --- |
| 只有一件事可做：一句话 + 按钮位置图 | `?debug=1` 打开，1024×576 与 1920×1080 各截一张 |
| 不预告场景（热切换后无意义） | 页面内不出现 `// 01 / 04` 与场景名 |
| 状态行分三档：设备 / 需要重按 / 需要工作人员 | 用 `?retry=1` 看 hint 行；断网看设备行 |
| 不出现内部术语（WebXR/BLE/协议） | 全文搜索 `src/ui/strings.ts` 与 `src/index.html` |
| 结束态不改写为"再来一次" | 会话结束后应为"训练已结束 · 请保持姿势" |

## 3 VR 内像素 UI

| 判据 | 复现 |
| --- | --- |
| HUD / 字幕 / SUS / 记录卡同一套字体与细线 | 实机截四张（或 `?debug=1` 2D 预览看 HUD） |
| SUS 三行题面不压答案行 | 实机：最长题（第 2、9 题） |

| 记录体位卡片不要求朝向 | 卡片文案不含"看向" |
