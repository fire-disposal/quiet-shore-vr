# 系统总介绍（起草版）

目的：把"静岸"讲清楚、讲好听。本文是**唯一的总介绍来源**，站点首屏、README、说明书开口、技术员口头介绍都从这里取。

## 1 名字与定位

| 项 | 定稿 |
| --- | --- |
| 名称 | 静岸 · Quiet Shore VR |
| 副题 | 躺在床上，看见另一处风景 |
| 一句话定位 | 在床边完成的多场景沉浸式体验：躺着，也能去别处待一会儿 |
| 类目词 | 沉浸式场景体验（不用"治疗""训练系统""康复方案"） |

场景是内容，不是身份：湖面只是三个场景之一，介绍里以"场景体验"总称。

## 2 三个长度

**一句（10–25 字）**
> 躺着，也能去别处待一会儿。

**短（约 90 字，站点副标题与 README 首段）**
> 静岸是一套在床边完成的沉浸式场景体验。患者保持躺着或半躺，戴上头显就进入一处安静的景物——湖面、光井，或按真实尺度搭建的病房立便间。场景切换、起伏快慢与语音说明都在床边的平板上完成，任何时刻可以停止。整套系统离线运行，画面与会话数据不离开这两台设备。

**长（约 240 字，申报书、医院介绍、说明书开头）**
> 静岸面向需要长时间卧床的成年人。它不要求患者起身、转头或学习操作：戴好头显，看向画面中央的圆，按一次按钮，就进入一处缓慢移动的场景。世界以很慢的节奏轻轻起伏，水声垫在底下，工作人员的声音在需要时出现，说明正在发生什么、下一步做什么。
>
> 所有设置都在床边的平板上：选场景、调起伏、放语音、随时停止。系统不采集、不上传任何画面或生理数据；离线运行，一名工作人员即可完成一次完整体验。
>
> 静岸是一次体验：目标是让卧床的时间慢一点、安静一点。

## 3 面向患者的口头版（30 秒）

> "待会儿戴上这个头显，会看到一处很安静的风景。画面会慢慢地一起一伏，很慢，还有水声。您不用做别的，看着听着就行。不舒服就说一声，我马上停。"

## 4 三个场景怎么说

| 场景 | 对外说法 |
| --- | --- |
| 仰望湖面 | 躺着看天：云、水面和一条日光 |
| 光井 | 一条竖直的光，边缘缓慢流动 |
| 洁净立便间 | 按真实尺度搭建的病房卫生间，视角可缓缓升起 |

## 5 适合

- 需要长时间卧床、愿意看看屏幕里风景的成年人。
- 有一名工作人员能在床边陪伴、随时停止的安排。
- 愿意尝试头戴设备的患者；第一次使用由工作人员协助戴好。

## 7 说话的红线

- 只做体验陈述：不承诺疗效，不出现"治疗""改善症状""临床验证"。
- 只描述看到与听到的，不描述患者身体感受。
- 不用"沉浸式元宇宙""数字疗法""AI 陪伴"这类词。
- 对患者称"您"；书面称"参与者"。
