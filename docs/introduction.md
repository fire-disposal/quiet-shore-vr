# 系统总介绍

本文是唯一的总介绍来源：站点首屏、README、说明书开口、技术员口头介绍都从这里取。

## 1 名字与定位

| 项 | 定稿 |
| --- | --- |
| 名称 | 静岸 · Quiet Shore VR |
| 副题 | 躺在床上，换个地方待一会儿 |
| 类目 | 床边的沉浸式场景体验 |

## 2 三个长度

**一句**
> 躺着，也能换个地方。

**短（站点副标题、README 首段）**
> 静岸是一套床边的沉浸式场景体验。戴好头显，进入一段安静的画面与声音；技术员在平板上控制节奏，随时可以停。

**长（申报书、说明书开头）**
> 静岸是一个实验性项目：为卧床患者提供一段沉浸式的场景体验。戴好头显即可开始，节奏由床边的技术员掌握，任何时候都能停下。我们希望它在真实的卧床场景里用得住，也需要使用者的反馈来改进。

## 3 给患者的口头介绍（30 秒）

> "这是一个实验性项目，想看看它在床边用起来怎么样。待会儿戴上头显会进入一段安静的画面，节奏我来控制，不舒服就说停。您的反馈会帮我们改进，谢谢您帮忙。"

## 4 投放位置

| 位置 | 用哪一版 |
| --- | --- |
| 站点首屏 | 副题 + 短版 |
| README 首段 | 短版 |
| 说明书写开头 | 长版 |
| 技术员口头 | 30 秒版 |
| 头显"开始前说明"页 | 长版 + 一句致谢 |

## 5 说话的红线

- 只做体验陈述：不承诺疗效，不出现"治疗""改善症状""临床验证"。
- 只描述看到与听到的，不评价患者身体。
- 不用"元宇宙""数字疗法""AI 陪伴"这类词。
- 不铺陈功能与场景清单；一句话说清"是什么、谁在用、怎么停"。
