# 系统总介绍

本文是唯一的总介绍来源。站点首屏、README、说明书开口、技术员口头介绍都从这里取。

## 1 名字与定位

| 项 | 定稿 |
| --- | --- |
| 名称 | 静岸 · Quiet Shore VR（临时名，正式材料中不出现） |
| 副题 | 躺在床上，换个地方待一会儿 |
| 类目 | 床边的场景体验 |

类目只写"场景体验"。更长的修饰语属于内部说法，患者与技术员都不需要。

## 2 三个长度

### 一句

> 躺着，也能看见站立时的视野。

### 短（站点副标题、README 首段）

> 静岸是一套床边的场景体验。患者在躺卧的体位下，看见近似站立时的视野。节奏由技术员掌握。患者按一次头显上的按钮确认开始，随时可以说停。

### 长（申报书、说明书开头）

> 静岸是一个实验性项目。患者躺卧时，通过画面与声音获得近似站立时的视野。画面与声音缓慢柔和。节奏由床边的技术员掌握，任何时候都能停下。项目需要在真实的卧床场景里使用，也需要使用者的反馈来改进。

## 3 致患者的说明（正式、简短）

用于纸质同意单与床边口述，不出现品牌名。

### 书面版（约 130 字）

> 尊敬的患者，您好。
>
> 我们正在做一项场景体验的技术测试。您躺卧时，画面与声音会带来近似站立时的视野。我们想了解这种体验在卧床条件下实际怎么用。
>
> 全程约十分钟。画面与声音缓慢柔和。进入时请您按一次头显上的按钮，之后由工作人员调整。任何时候您说停，或再按一次同一个按钮，都会立即停下。结束后想请您说几句感受。谢谢您。

### 口头版（30 秒，技术员照读）

> "尊敬的患者，您好。我们在做一项场景体验的技术测试。让您躺着的时候，也能看到站立时的视野，看看它在床边用起来是否合适。节奏由我掌握。您说停，或者按一下头显上的按钮，都会马上停下。结束后想请您说几句真实感受。谢谢您。"

### 三条要求（写进流程）

1. 先说清"是测试、不是治疗"，用"技术测试""体验"的说法，不承诺效果。
2. 说清"随时可以停"和怎么停：说一声，或按一次头显上的按钮；工作人员也会立即停。
3. 结束后索取反馈并致谢，不追问隐私内容。

## 5 说话的红线

- 只陈述体验：不承诺疗效，不出现"治疗""改善症状""临床验证"。
- 只描述看到与听到的，不评价患者身体。
- 不用"元宇宙""数字疗法""AI 陪伴"这类词。
- 不铺陈功能与场景清单。一句话说清是什么、谁在用、怎么停。
