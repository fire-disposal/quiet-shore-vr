# 系统总介绍

本文是唯一的总介绍来源：站点首屏、README、说明书开口、技术员口头介绍都从这里取。

## 1 名字与定位

| 项 | 定稿 |
| --- | --- |
| 名称 | 静岸 · Quiet Shore VR（临时名，正式材料中不出现） |
| 副题 | 躺在床上，换个地方待一会儿 |
| 类目 | 床边的沉浸式场景体验 |

## 2 三个长度

**一句**
> 躺着，也能看见站立时的视野。

**短（站点副标题、README 首段）**
> 静岸是一套床边的沉浸式场景体验：在躺卧的体位下，获得近似站立时的视野与感受。戴好头显即可开始，节奏由技术员掌握，随时可以停。

**长（申报书、说明书开头）**
> 静岸是一个实验性项目：让卧床患者在躺卧的体位下，获得近似站立时的视野与感受。画面与声音缓慢柔和，节奏由床边的技术员掌握，任何时候都能停下。我们希望它在真实的卧床场景里用得住，也需要使用者的反馈来改进。

## 3 致患者的说明（正式、简短）

用于纸质同意/告知单、床边口述、头显"开始前说明"页。不出现品牌名。

**书面版（约 130 字）**

> 尊敬的患者，您好！
>
> 我们正在进行一项 VR 场景体验的技术测试：在躺卧的体位下，借由画面与声音，让您获得近似站立时的视野与感受，并了解这种体验在卧床条件下的实际使用情况。
>
> 全程约十分钟：画面与声音缓慢柔和，开始与结束均由工作人员操作，您随时可以提出停止。恳请您配合，并在结束后给予简短反馈，帮助我们改进。感谢您的支持与帮助。

**口头版（30 秒，技术员照读）**

> "尊敬的患者，您好。我们在做一项 VR 场景体验的技术测试：让您躺着的时候，也能感受到站立时的视野和氛围，看看它在床边用起来是否合适。节奏由我掌握，任何时候您说停我就停。结束后想请您说几句真实感受，帮我们改进。谢谢您。"

**三条要求（写进流程）**

1. 先说明"是测试、不是治疗"——用"技术测试/体验"的说法，不承诺效果。
2. 明确"随时可以停"，并说明由谁执行（工作人员）。
3. 结束后索取反馈，并致谢；不追问隐私内容。

## 5 说话的红线

- 只做体验陈述：不承诺疗效，不出现"治疗""改善症状""临床验证"。
- 只描述看到与听到的，不评价患者身体。
- 不用"元宇宙""数字疗法""AI 陪伴"这类词。
- 不铺陈功能与场景清单；一句话说清"是什么、谁在用、怎么停"。
