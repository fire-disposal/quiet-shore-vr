# 系统总介绍（起草版）

目的：把"静岸"讲清楚、讲好听，且不越界。本文是**唯一的总介绍来源**，站点首屏、README、说明书开口、技术员口头介绍都从这里取。

## 1 名字与定位

| 项 | 定稿 |
| --- | --- |
| 名称 | 静岸 · Quiet Shore VR |
| 副题 | 躺在床上，看见水面 |
| 一句话定位 | 把湖面搬到床边：一趟躺着就能完成的沉浸式放松体验 |
| 类目词 | 沉浸式放松体验（**不**用"治疗""训练系统""康复方案"） |

口语里可以叫"静岸""湖面体验"；不要简称"VR 训练仪"。

## 2 三个长度

**一句（10–25 字，用于标题下、分享卡片）**
> 把湖面搬到床边，躺着也能慢慢安静下来。

**短（约 90 字，用于站点副标题、README 首段）**
> 静岸是一套床边的沉浸式放松体验。患者保持躺着或半躺，戴上头显，眼前是一片缓慢起伏的湖面、光井或病房立便间，耳边有水声与工作人员的声音。场景切换、起伏快慢、语音播报都由床边的平板完成，任何时刻可以停止。整套系统离线运行，画面与会话数据不离开这两台设备。

**长（约 240 字，用于申报书、医院介绍、说明书开头）**
> 静岸面向需要长时间卧床的患者。它不要求患者起身、转头或学习操作：戴好头显，看向画面中央的圆，按一次按钮，就进入一片缓慢移动的景物——湖面、光井，或一间按真实尺度搭建的病房立便间。世界会以很慢的节奏轻轻起伏，水声垫在底下，工作人员的声音在需要时出现，说明正在发生什么、下一步做什么。
>
> 所有设置都在床边的平板上：选场景、调起伏、放语音、随时停止。系统不采集、不上传任何画面或生理数据；设备离线运行，一名工作人员即可完成一次完整会话。
>
> 静岸是一次体验，不是诊断或治疗手段。它的目标是让卧床的时间慢一点、安静一点。

## 3 面向患者的口头版（30 秒，技术员照读）

> "待会儿会戴上这个头显，里面是一片湖。湖面会慢慢地一起一伏，很慢，还有水声。您不用做别的，看着听着就行。不舒服就说一声，我马上停。"

## 4 三个场景怎么说

| 场景 | 对外说法 | 不这么说 |
| --- | --- | --- |
| 仰望湖面 | 躺着看天：云、水面和一条日光 | "湖景放松舱" |
| 光井 | 一条竖直的光，边缘缓慢流动 | "冥想空间" |
| 洁净立便间 | 按真实尺度搭建的病房卫生间，可缓缓升起视角 | "模拟排尿训练" |

## 6 说话的红线

- 不承诺疗效，不出现"治疗""改善症状""临床验证"。
- 不描述患者身体状态（"你会想尿"之类），只描述看到与听到的。
- 不用"沉浸式元宇宙""数字疗法""AI 陪伴"这类词。
- 不把患者称作"受试者"（对患者说"您"；书面可用"参与者"）。
