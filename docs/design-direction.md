# 设计裁定：曲院风荷

不是红金国风，也不是深色仪表盘。方向是**现代中式园林的留白、窗景和游线**，服务卧床患者的安静使用场景。

## 1. 视觉语言

| 角色 | 选择 | 用途 |
| --- | --- | --- |
| 纸 | `#F3EFE6` | 主背景，替代深色渐变 |
| 墨 | `#20251F` | 正文与主按钮 |
| 苔 | `#5E655A` | 次级文字 |
| 锈红 | `#8F4634` | 唯一强调色，用于选择、状态和主操作 |
| 水绿 | `#486B58` | 成功与连接状态 |
| 石线 | `#D5CCBB` | 分隔线、边框 |

- 两个字体家族：中文标题用宋体风格，界面与正文用无衬线。
- 不使用金色、发光、玻璃拟态、厚阴影、胶囊堆叠。
- 场景选择是编号游线，不是卡片网格；右侧是取景窗式场景预览。
- 动画只表达状态，且尊重 `prefers-reduced-motion`。

## 2. 适用的 skill 建议

### ui-design

- 采用：一个主 CTA、一个主焦点、非对称双栏、1200 左右内容宽度、清晰三级层次、控件全状态、设计 token。
- 调整：间距向 8px 基准靠拢；减少同一视口的字号数量。
- 不采用：为了 12 列而 12 列；固定 64-96px 大区块间距会撑爆 720p 头显视口。

### visual-direction

- 采用：暖中性色、单色强调、最多两个字体家族、标题与正文强对比、留白、无库存图。
- 调整：先做纸面浅色，而不是 2026 常见的 dark-first；深色只留给沉浸式三维窗口。
- 不采用：oversized 100px hero、渐变趋势色、装饰性 3D。

### web-typography

- 采用：宋体标题 + 黑体正文、标题与正文明显比例、1.5-1.75 行高、限制行宽。
- 调整：正文尽量靠近 15-16px；小号仅用于标签和控制提示。
- 不采用：用下划线表示强调；次要操作改为描边按钮。

### color-theory

- 采用：一个主强调 + 一个语义绿 + 中性纸色，60-30-10。
- 验证：纸底上墨字 13.6:1；苔色 5.25:1；锈红 5.92:1；锈红底纸字 4.65:1。
- 调整：原 `#6D7468` 和 `#A9563E` 在纸面上不足 4.5:1，已加深。
- 不采用：颜色作为唯一状态信号；选中项同时有文字“已选”和索引变化。

### accessibility

- 采用：可缩放的 viewport、44-48px 触控目标、可见焦点、非颜色状态、减少动画。
- 待补：头显端 Android 控件的 TalkBack 实测；主页面 skip link。
- 不采用：用 `maximum-scale=1` 阻止缩放；已移除。

### design-trends

- 采用：状态驱动的微动效、字体作为主视觉、非对称布局。
- 不采用：dark-first、bento 卡片墙、滚动叙事、自定义光标、自动轮播。这些会强化 AI 模板感，也不适合头显 2D 视口。

## 3. 与场景契约的关系

- 场景声明自己的音频，应用不按场景 ID 选择声音。
- 场景只构建自己的 root 和更新循环，不控制会话、菜单、BLE。
- 新增场景只注册 `SceneDefinition`，不往 App 增加业务分支。
- 细节见 `docs/scene-contract.md`。

## 4. 后续检查

1. 720p 头显视口首屏是否仍能看全场景列表与主操作。
2. 纸面文字与实际头显亮度下的可读性。
3. 平板纸面主题与暗色三维视口的对比是否过强。
4. 设置页的 Switch 和导航是否能用准星稳定点中。
