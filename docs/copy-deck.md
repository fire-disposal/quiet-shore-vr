# 文案对照表（患者侧 / 技术员侧）

状态：2026-10-24，随 0.9.23 生效。整体说法见 `docs/introduction.md`，两者冲突时界面短句服从本表。新增或修改任何界面文案、语音文本前，先在此表登记。

## 1 术语决定

| 概念 | 患者侧叫法 | 技术员侧叫法 | 不用 |
| --- | --- | --- | --- |
| 整个流程 | 体验 | 训练 / 会话 | 治疗、疗程 |
| 操作设备的人 | **工作人员** | 技术员 | 医生、操作员 |
| 记录起始方向 | 记录现在看向的方向 | 校准 | 标定、对齐 |
| 立即停止 | 停下 | 急停 | 中止 |
| 计划内结束 | （患者不操作） | 结束 | 停止、退出 |
| 背景音 | 水声 | 水声 / 环境声 | 白噪音 |
| 语速/幅度 | 起伏 | 强度、档位 | 音量（那是另一项） |
| 场景 | 洁净立便间 / 仰望湖面 / 光井 | 同左 | 洗手间、湖景 |

规则：患者侧第二人称一律"您"；一句 ≤ 14 字；不评价、不许诺、不催促；技术员侧用动词开头（启动、结束、校准）。

## 4 语音文本（27 句，与界面一致）

| 组 | 条目 | 措辞规则 |
| --- | --- | --- |
| 说明 | 开场（技术测试目的 + 三件事 + 不适处理 + 致谢）、结束致谢 | 只陈述事实与动作；不含数值时长 |
| 引导 | 进入、安全、校准、漂浮、想象、放松、收束、结束、起身 | 患者侧称"工作人员"；停止一律"按头显右侧的按钮"；"现在的姿势"不写仰卧 |
| SUS | 说明 + 10 题 | 量表原文，逐字不改 |

已对齐的具体改动：

- `v-close-1` 由"训练即将结束"改为"**这次体验**即将结束，画面会慢慢淡出。"
- 页脚、控制台页脚统一为"若（您）感到不适，请立即告知工作人员"。
- 控制台主页由"等待操作员提示"改为"等待工作人员"。

## 5 每轮改动的检查项

1. 新文案是否出现在本表（没登记就不合入）。
2. 同一动作在患者侧与技术员侧是否用了各自规定的词。
3. 是否引入了评价、承诺、催促或精确数值。
4. 语音文本与界面用词是否一致（"校准"不出现在患者侧语音里）。
