# 应用层级（App level）

状态：2026-11-12 起草并落地 H1–H4。引入原因：问卷产品线要从训练里独立出来，而
"顶栏只有一个 `i`、只有一份说明书、主区域只有一套内容"这三件事都是按单应用写死的。

实现：`app:training|app:questionnaire` 命令下行；页面把 `app` 放进状态 JSON，头显转发到
`flags`，平板顶栏显示的是头显回报的值。切应用在会话中拒绝；`i` 按当前应用打开各自说明书。
问卷题目由页面 `src/questionnaire/registry.ts` 单一来源下发，平板只渲染收到的题目与选项；
训练记录与问卷记录写同一份本机记录文件，用 `app` 字段区分。

## 1 什么是"应用"

**应用 = 一个可在主区域切换的产品面**，各自拥有：主区域内容、自己的说明书、自己的
会话/记录语义。当前两个：

| 应用 | 主区域 | 说明书 |
| --- | --- | --- |
| 训练（session） | 会话/场景/语音/量表（现有四段） | 现有《操作说明》：校准、分段、结束 |
| 问卷（questionnaire） | VR 问卷环境：题目、作答记录、导出 | 问卷自己的说明：如何施测、如何导出 |

外壳（顶栏、导轨、初始页）不随应用变化；**变的是主区域与说明书的指向**。

## 2 顶栏的布局约定

```
[信号] 已连接 EEFF │ 两条电量条 │ [当前应用 ▾] │ (i) │ [断开连接]
                                   ↑ 电量列左让位给它
```

- `当前应用 ▾`：平时只显示应用名，点击向下弹出列表切换。
- `(i)`：**指向当前应用的说明书**——先切应用，再点 `i`，打开的就是它自己的说明。
  没有"全局说明书"这个入口（通用操作写在各自说明书的第一节）。
- 电量条为它让出宽度：两条读数各收窄，仍保持"文字在条内、色带在条内"。

## 3 同步

- 控制端切换应用 → 发命令（建议 `app:<id>`）→ 页面切换主区域内容；
- 页面把自己的当前应用回报（走现有 JSON 通道的 `flags` 或独立文档），
  控制端顶栏因此显示的是**头显正在跑的应用**，而不是本地点了什么；
- 两者不一致时（切换失败/断链），顶栏显示头显侧的值，并在链路横幅里说明。

## 5 记录上传（单向遥测）

本机仍是权威副本；上传只是把同一批记录另送一份到聚合端，**不影响导出、导出不依赖上传**。

- **端点固定** `https://205716.xyz/vrdata/`，设备侧无账号、不读取、不提供设置项。服务器另有口令保护的读取页 `/vrdata/admin/`（筛选、分页、单条详情、按当前筛选导出 CSV），只给人用；未配置口令时该页与其全部接口回 `404`。部署与接口见 [server/README.md](../server/README.md)。
- **四种记录**全部接入：问卷结果（`questionnaire`）、训练会话（`training`）、体验记录
  （`experience`）、行为事件（`event`）。
- **先入持久 outbox，再算可上传**：`TelemetryRecorder` 在每次本地写入后同步写
  outbox，然后才请求一次上传。断网、上传被合并、进程被杀都不丢记录。
- **ID 幂等**：`<家族>:<SHA-256(本地稳定键)>`，匹配 `[A-Za-z0-9._:-]{1,128}`。
  问卷用 `QuestionnaireResult.key`，训练用页面会话戳，体验用记录 `id`，
  事件用页面 `d.id` 或整条已存记录的哈希。重发/重放由服务端按 `id` 去重。
- **`occurredAt`** 是 ISO-8601 UTC 字符串（毫秒 + `Z`）；本地 millis 一次性归一化，
  平板时区不上线。服务端允许带偏移的输入，按同一瞬时归一。
- **ACK 才出队**：只有响应 `acknowledged` 里**且属于本批**的 id 才删除；200 但无有效
  ack 视为失败并退避（1/2/4/8… 分钟，上限 30 分钟）。
- **调度**：WorkManager 周期 15 分钟 + 联网约束；应用启动与新记录触发一次性上传。
  周期任务 `KEEP`、一次性任务 `APPEND_OR_REPLACE`，加上进程内单飞，
  保证不会并发重复上传同一批。
- **回填**：冷启动把本机已有记录排入 outbox；已 ACK 的 id 不再入队，
  因此每次启动都不会重复上传。

实现：`android/control/.../data/telemetry/`。
