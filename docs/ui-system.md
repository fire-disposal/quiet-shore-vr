# 界面系统：一套变体，三个表面

状态：定稿（2026-11-12，v1.0.0）。本文件只记"长什么样、为什么"，不记实现细节；实现在各自的文件里。

## 1 变体卡

```text
变体：冷库（ice #7DE6FF / cool 纸 / tight 切角 / plain 底纹 / standard 密度 / calm 动效）
主视觉：入口页只放事实——场景号、场景名、一句动作、按钮位置图
```

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 强调色 | ice `#7DE6FF` | 冷、精确。amber 属于「工地」预设，不要混用 |
| 纸 | cool | 深色：纸 `#171a1c`、板 `#1f2326`；浅色：纸 `#F4F4F2`、板 `#FFFFFF` |
| 切角 | tight | 只有一个角，且只给可按元素 |
| 底纹 | **plain** | 不要等高线、网格、斜纹——本项目一律无装饰纹 |
| 密度 | standard | 触控目标 ≥ 48dp |
| 动效 | calm | 去入场动画，只留回应操作与进出 |

固定规则（任何表面都不许违反，来自 `endfield-ui`）：

1. 只有一种强调色，只表示"当前 / 可按 / 需注意"，只做填充；浅色底上压墨字 `#161616`（12.6:1），深色底上才可当强调文字色。
2. 红色只给删除与急停（`急停` 是唯一保留的红色动作）。
3. 细线（1px，墨色 12–16%）分区；不用卡片堆叠、投影、发光、渐变；圆角一律 0。
4. 中文黑体、不加字距；小号拉丁标签全大写 + 字距 .14em；数字等宽（tabular）。
5. 编号、场景序号、时长、强度都是真实数据，不编造。
6. 文案一句一个事实、动作用动词、不写风格词、不向患者暴露内部术语。

## 2 三个表面

| 表面 | 文件 | 底色 | 字号档 | 强调色用法 |
| --- | --- | --- | --- | --- |
| 患者 2D 入口页 | `src/index.html` + `src/styles.css` | 深色纸 `#171a1c` | 指令 34–60、副句 17–23、状态 15–17、页脚 12 | 状态标记与"需注意"文字 |
| VR 内像素 UI | `src/core/spatial/theme.ts` + `src/ui/**` | 浅色面板（低眩光） | 见 `theme.ts` 的 `titlePx/bodyPx/buttonPx` | 选中/当前按钮填充 + 墨字 |
| 平板控制台 | `android/control/**` | 浅色纸 `#F4F4F2` | 见 `ControlTheme.kt` | 选中/当前/需注意填充 + 墨字；急停红 |
| 场景镜像 | `src/mirror/main.ts` | 深色纸 `#171a1c` | 13 | 视锥线用 ice（45% 不透明） |
| 头显控制台 APK | `android/headset/.../PortalActivity.kt` | 浅色纸 `#F4F4F2` | 见 `PortalActivity` 常量 | 选中/当前填充 + 墨字；电量 ≤20% 用 ice；急停保留 DANGER |

入口页的层级是固定的，从上到下：场景字段行（`// 01 / 04 场景`）→ 场景名 → 唯一的动作句 → 按钮位置图 → 细线分隔的状态区（设备状态 + 一条次要报告 + 重试引导）→ 页脚。

提示优先级：**sticky**（重试、结束）永远压过 **transient**（连接、语音、播放失败）。

### 2.1 头显电量横栏

电量的唯一显示位置是**头显控制台 APK 的首页**（不是 WebXR 入口页：那是 FxR 里的门，患者只需要一次按压）。

```text
头显电量                                        62% 充电中
██████████████████████░░░░░░░░░░░░░░░░░░
```

- 数据来自 `ACTION_BATTERY_CHANGED` 粘性广播，Activity 自己注册（`onResume`/`onPause`），拿不到值就整条隐藏——不画假数据。
- 进度条铺满卡片内容区、高 10–12dp、圆角 0、ice 填充；数字等宽。
- `≥100%` 且接着电源写「已充满」，其余接电写「充电中」；`≤20%` 时数字与标签换成 ice（需注意），不用红色。
- 同一条数据也在 `/status.battery` 与 WS 的 `battery` 消息里（见 `docs/control-plane.md` §5.1），供诊断与将来的镜像/平板使用。

## 3 这一轮改了什么

- 入口页：去掉背景径向渐变、圆角状态药丸、手柄示意图的虚线纹；标题从绝对定位居中改为字段行 + 细线；字号上调一档；示意图缩小约 30%（只改配色，几何未动）。
- VR 内：主题从"暖纸 + serif + 赤陶色"换成"白色面板 + 黑体 + ice 填充"，圆角归零，成功态改墨色，按钮选中态改填充。
- 平板：主色从赤陶色换 ice，字体从 serif 换 sans，圆角归零，状态行收敛为一句短语。
- 镜像：底色与标签跟同一变体，字段分隔改 `│`。
